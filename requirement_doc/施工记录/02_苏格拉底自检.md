# 苏格拉底自检记录 (2026-02-20)

## 对 v1 开发计划的反问与发现

### 问题 1: 通信协议缺失
Server 和 Extension 之间的 WebSocket 消息格式没有先行设计。
如果协议没定好，Phase 1 和 Phase 2 写出来的东西对不上。
**修正：** 新增 Phase 0 — 协议设计，先定义 JSON Schema 再动手写代码。

### 问题 2: 并发任务排队
需求提到 `activeTasks` Map，但如果 Agent 同时发了两个请求，
Content Script 在同一个 Tab 里无法并行操作 DOM。
**修正：** 在 Background 层增加任务队列，同一 Tab 串行执行。

### 问题 3: MV3 Service Worker 休眠
MV3 的 Service Worker 约 30 秒无活动就会被终止，
简单的"断线重连"不够，需要 Offscreen API 或 Keep-alive 心跳策略。
**修正：** Phase 2 中将 Keep-alive 方案作为重点项，而非一笔带过。

### 问题 4: 错误链路缺失
AI 页面未登录、DOM 结构变更、网络超时等异常场景，
错误如何回传给 Agent 客户端？计划完全没提。
**修正：** 定义统一错误格式，在协议层和各 Phase 中补充错误处理。

### 问题 5: Anthropic 兼容接口遗漏
需求明确提到 OpenAI + Anthropic 两种格式，
但 v1 计划只有 `/v1/chat/completions`，缺少 `/v1/messages`。
**修正：** Phase 1 中补充 Anthropic 端点。

### 问题 6: 插件交付节点不清晰
Chrome 插件被拆散在 Phase 2/3/4，没有明确的"可交付"节点。
**修正：** 新增 Phase 5 — 集成联调与打包交付，作为插件和 Server 的统一交付点。

### 问题 7: pkg 打包无正式阶段
需求要求最终打包为 `.exe`，v1 计划只在备注提了一句。
**修正：** 纳入 Phase 5。
