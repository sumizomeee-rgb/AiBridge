# Phase 0: 通信协议设计

## 1. WebSocket 消息总览

所有 WebSocket 消息均为 JSON 格式，通过顶层 `type` 字段区分类型。

**方向约定：**
- `S→E` = Server 发给 Extension (Background)
- `E→S` = Extension (Background) 发给 Server

---

## 2. 心跳保活

### S→E: ping
```json
{ "type": "ping" }
```

### E→S: pong
```json
{ "type": "pong" }
```

Server 每 15 秒发一次 ping，超过 30 秒未收到 pong 视为断连。
Extension 侧收到 ping 立即回 pong。

---

## 3. 任务下发

### S→E: task
```json
{
  "type": "task",
  "task_id": "uuid-xxxx",
  "model": "gpt-4",
  "messages": [
    { "role": "user", "content": "你好" }
  ],
  "stream": true,
  "new_chat": true
}
```

字段说明：
- `task_id`: 唯一标识，用于关联后续所有回传消息
- `model`: 模型标识，Auto 模式下用于路由匹配
- `messages`: 统一为 OpenAI 格式的消息数组（Server 负责将 Anthropic 格式转换）
- `stream`: 是否流式返回
- `new_chat`: 是否需要新建会话

---

## 4. 流式回传

### E→S: chunk
```json
{
  "type": "chunk",
  "task_id": "uuid-xxxx",
  "delta": "这是增量文本"
}
```

### E→S: done
```json
{
  "type": "done",
  "task_id": "uuid-xxxx"
}
```

Content Script 每次 MutationObserver 检测到新增文本时发送 chunk。
AI 回复结束后发送 done，Server 收到后关闭该 task 的 SSE 连接。

---

## 5. 错误回传

### E→S: error
```json
{
  "type": "error",
  "task_id": "uuid-xxxx",
  "code": "NOT_LOGGED_IN",
  "message": "目标 AI 页面未登录"
}
```

### 错误码定义

| code | 含义 |
|------|------|
| `NOT_LOGGED_IN` | 目标 AI 页面未登录 |
| `TAB_NOT_FOUND` | 未找到目标 AI 的标签页且无法创建 |
| `DOM_TIMEOUT` | DOM 操作超时（如找不到输入框、发送按钮） |
| `RATE_LIMITED` | 目标 AI 返回速率限制提示 |
| `UNKNOWN` | 未分类错误 |

Server 收到 error 后，将其转换为对应 HTTP 格式的错误响应返回给 Agent 客户端。

---

## 6. 模型路由映射表 (Auto 模式)

| model 字段包含 | 目标平台 | URL 匹配 |
|---------------|---------|----------|
| `gpt` | ChatGPT | chatgpt.com |
| `doubao` | 豆包 | doubao.com |
| `claude` | Claude | claude.ai |
| `qwen` | 通义千问 | tongyi.aliyun.com |

Background 在 Auto 模式下根据此表匹配目标 Tab。

## 7. Server 外部接口映射

### OpenAI 格式 `POST /v1/chat/completions`

请求体直接提取 `model` 和 `messages` 字段，映射到内部 task 格式。

SSE 返回格式：
```
data: {"choices":[{"delta":{"content":"增量文本"}}]}

data: [DONE]
```

### Anthropic 格式 `POST /v1/messages`

请求体中 `model` 和 `content` 字段需转换为内部统一的 messages 数组格式。

SSE 返回格式：
```
event: content_block_delta
data: {"type":"content_block_delta","delta":{"type":"text_delta","text":"增量文本"}}

event: message_stop
data: {"type":"message_stop"}
```
